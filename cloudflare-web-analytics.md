# Инструкция: завести сайт в Cloudflare Web Analytics и получить токен счётчика

Получить токен счётчика Cloudflare Web Analytics для сайта, который хостится не в Cloudflare
(GitHub Pages и т.п.). Токен — 32 символа, он вставляется в HTML страницы и **секретом не
является**: его видит любой, кто откроет исходный код страницы.

Составлена 2026-09-14 без сверки с экраном: если пункт меню называется иначе — ищи по смыслу
(«Web Analytics», «Add a site») и поправь инструкцию.

## Значения для подстановки

Имена в обратных кавычках в шагах ниже (`hostname`, `token-return`) — не текст для ввода, а места
для подстановки. Значения тебе дают вместе с этой инструкцией: ИИ-агент в сообщении или инструкция
задачи таблицей «поле → значение». Значения нет нигде — спроси ИИ-агента, а не угадывай.

| Поле | Что это | Пример |
|---|---|---|
| `hostname` | домен сайта без `https://` и без пути | `example.github.io` |
| `token-return` | куда отдать токен | команда `./add-analytics.sh <токен>` |

## Шаги

1. Открой https://dash.cloudflare.com и войди в аккаунт. Аккаунта нет — «Sign up», бесплатного
   плана достаточно; домен в Cloudflare переносить **не нужно**.
2. В левом меню открой **Analytics & Logs → Web Analytics**. Такого пункта нет — в строке поиска
   дашборда набери «Web Analytics».
3. Нажми **Add a site**.
4. В поле **Hostname** введи `hostname`.
5. Если спросят способ установки — выбери вставку JavaScript-фрагмента (**Manual / JS Snippet**),
   а не автоматическую установку: автоматическая работает только для доменов, чей DNS в
   Cloudflare.
6. Нажми **Done** / **Add**. Откроется страница с фрагментом кода вида:

   ```html
   <script defer src="https://static.cloudflareinsights.com/beacon.min.js"
     data-cf-beacon='{"token": "0123456789abcdef0123456789abcdef"}'></script>
   ```

   Сайт уже был добавлен раньше — в списке Web Analytics нажми **Manage site** у нужного
   `hostname`, фрагмент там же.
7. Скопируй из фрагмента **только значение `token`** — 32 символа между кавычками.
8. Отдай токен так, как написано в `token-return`.

Готово, когда токен отдан. Счётчик считает всё, что открыто на `hostname`, — отдельные страницы
потом различаются фильтром по пути (**Path**) в отчёте Web Analytics.

Необязательно: в настройках сайта в Web Analytics можно включить уведомления и выключить сбор
**Core Web Vitals** — на подсчёт визитов это не влияет.
