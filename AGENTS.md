# AGENTS.md — `instructions`: шаблоны инструкций для человека

Репозиторий хранит **шаблоны** повторяющихся действий, которые ИИ-агент поручает человеку: завести
OAuth-клиент, разрешить установку на телефоне, вставить промпт в чат нейросети. Человеку отдаётся не
шаблон, а собранная из него инструкция со значениями задачи; собирает `render`.

- Как пользоваться, формат шаблона и файла значений, раскладка — [`README.md`](README.md).
- Правило, по которому инструкции пишутся, — `~/Projects/github/m_pashka/ai/rules-on-demand/user-instructions.md`.
- Задачи репозитория — `docs/requests/<задача>/` (`request.md` + `plan.md`), план проекта —
  `requests-plan.md`; и то и другое вне git.

## Границы

- 🚨 **Репозиторий публичный** (`git@github.com:mpashka/instructions.git`): ничего рабочего
  (внутренние сервисы и устройство Яндекса), ничего личного (имена, адреса, номера документов,
  названия записей хранилища паролей) и ничего секретного. Конкретные значения живут в файле
  значений у задачи, секреты — ссылкой `{vault: …, key: …}`.
- 🚨 **Собранную инструкцию ИИ-агент не читает**: в ней бывают секреты открытым текстом. Проверять
  можно наличие файла и отсутствие `{{` (`grep -c`); человеку называется путь.
- Человек ищет поле или кнопку на чужом сайте — инструкция с рисунком экрана (`instruction.html`),
  а не Markdown. Соседний шаблон образцом формата не является.
- Тест перед коммитом: `python3 -m unittest discover -s tests` — рендерер и сборка каждого шаблона
  на его примерах, меньше секунды, без сети.
