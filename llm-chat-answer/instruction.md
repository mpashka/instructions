# Инструкция: промпт в чат нейросети → ответ файлом

Отправить готовый промпт из файла `{{prompt_file}}` в чаты нейросетей ({{models}}) и сохранить
каждый ответ Markdown-файлом в каталог `{{answer_dir}}`.

Составлена 2026-09-14 без сверки с экраном каждого чата: если кнопка называется иначе — ищи
по смыслу.

## Шаги — для каждого чата: {{models}}

1. Открой `{{prompt_file}}` в любом текстовом редакторе, выдели всё (`Ctrl+A`), скопируй (`Ctrl+C`).
2. Открой адрес чата, войди в аккаунт. **Начни новый чат** (кнопка «New chat» / «Новый чат» —
   обычно слева вверху): старая переписка в том же чате портит ответ.
3. Если в чате есть выбор модели или режима — выбери самый сильный из бесплатных. Режим
   рассуждения («Reasoning», «DeepThink», «Думать дольше») — **необязательно**, включай, если
   доступен.
4. Щёлкни в поле ввода сообщения внизу, вставь (`Ctrl+V`), отправь (`Enter` или стрелка).
   Чат отказался принять длинный текст — прикрепи `{{prompt_file}}` файлом (скрепка) и напиши в
   поле «Выполни задание из файла».
5. Дождись конца ответа: пропала кнопка «Stop» / «Остановить». Ответ оборвался на полуслове —
   напиши «продолжай» и дождись снова.
6. Под ответом нажми кнопку «Копировать» (значок двух листов). Её нет — выдели ответ мышью
   целиком и `Ctrl+C`.
7. Создай в `{{answer_dir}}` файл с именем из таблицы выше, вставь ответ, сохрани. Ответ шёл
   несколькими сообщениями («продолжай») — вставь их подряд в тот же файл.

Правка ответа руками не нужна: файл сохраняется как есть, со всеми опечатками модели.

## Как понять, что удалось

В `{{answer_dir}}` лежит по файлу на каждый чат, и ни один не обрывается на полуслове. Какой-то
чат не ответил — не страшно, двух-трёх ответов хватает. Когда закончишь, напиши ИИ-агенту:

```text
ответы в папке, готово
```
