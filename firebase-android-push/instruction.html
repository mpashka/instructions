Пуш-уведомления: Firebase для «{{app_nickname}}»

Подключить Firebase к проекту Google Cloud {{project_name}}, завести в нём приложение Android {{package_name}} и сохранить командой два скачанных файла: настройки приложения и ключ, которым сервер отправляет уведомления. Платить ничего не надо: бесплатного тарифа Spark хватает. Время — минут 10.

ИИ-агент — Claude, Codex или другой ИИ-агент, от которого ты получил эту инструкцию.

1Подключить Firebase к проекту {{project_name}}

Открой https://console.firebase.google.com/ под тем же аккаунтом Google, которым заводил проект {{project_name}} в Google Cloud. Проект {{project_name}} уже есть в списке проектов Firebase — открой его и переходи к шагу 2.

Нет — под карточкой создания проекта нажми ссылку {{console-firebase:add-firebase-to-gcp}}. Новый проект не создавай: Firebase подключается к уже существующему.

{{project_name}}

{{console-firebase:continue}}

По пути Firebase попросит принять условия и подтвердить тариф — соглашайся с тарифом Spark, платёжный аккаунт не нужен. Помощник Gemini — как предложено, на работу не влияет. Удалось, если открылась страница проекта {{project_name}} в Firebase.

Firebase отвечает, что такое приложение уже есть, — значит, его заводили раньше: шестерёнка рядом с «Project Overview» → {{console-firebase:project-settings}}, внизу вкладки карточка приложения {{package_name}} и в ней та же кнопка скачивания.

3Скачать ключ для отправки уведомлений

Шестерёнка рядом с «Project Overview» слева вверху → {{console-firebase:project-settings}} → вкладка {{console-firebase:service-accounts}}.

{{console-firebase:project-settings}}… · {{console-firebase:cloud-messaging}} · {{console-firebase:service-accounts}}
{{console-firebase:firebase-admin-sdk}}
{{console-firebase:generate-new-private-key}}
окно подтверждения: {{console-firebase:generate-key}}

В «Загрузках» появится файл вида {{project_name}}-firebase-adminsdk-….json. Каждое нажатие создаёт новый ключ — нажимай один раз.

4Сохранить оба файла командой

Открой терминал и запусти — команда сама найдёт оба файла в «Загрузках»:

{{save_command}}

Удалось, если команда напечатала строку, начинающуюся с ГОТОВО. Скачанные файлы команда удаляет сама — ключ остаётся только в хранилище.

Файлы лежат не в «Загрузках» — допиши к команде через пробел пути к обоим файлам, в любом порядке.
