# Инструкция: промпт в чат нейросети → ответ файлом

Отправить готовый текст промпта в чат нейросети и сохранить её ответ в Markdown-файл, из
которого агент дальше соберёт сравнение.

Составлена 2026-09-14 без сверки с экраном каждого чата: если кнопка называется иначе — ищи
по смыслу и поправь инструкцию.

## Значения для подстановки

Имена в обратных кавычках в шагах ниже (`prompt-file`, `answer-dir`, …) — не текст для ввода, а места для
подстановки. Значения тебе дают вместе с этой инструкцией: ИИ-агент в сообщении или инструкция
задачи таблицей «поле → значение». Значения нет нигде — спроси агента, а не угадывай.

| Поле | Что это | Пример |
|---|---|---|
| `prompt-file` | файл с готовым промптом | `ready/facebook.md` |
| `answer-dir` | каталог для ответов | `answers/facebook/` |
| `models` | в каких чатах прогнать | ChatGPT, DeepSeek, Claude, Алиса |

## Чаты и имя файла ответа

| Модель | Адрес | Имя файла |
|---|---|---|
| ChatGPT | https://chatgpt.com | `chatgpt.md` |
| DeepSeek | https://chat.deepseek.com | `deepseek.md` |
| Claude | https://claude.ai | `claude.md` |
| Алиса | https://alice.yandex.ru | `alice.md` |
| Gemini | https://gemini.google.com | `gemini.md` |
| Grok | https://grok.com | `grok.md` |
| другая | — | латиница, строчные, без пробелов: `mistral.md` |

## Шаги — на каждую модель из `models`

1. Открой `prompt-file` в любом текстовом редакторе, выдели всё (`Ctrl+A`), скопируй (`Ctrl+C`).
2. Открой адрес чата, войди в аккаунт. **Начни новый чат** (кнопка «New chat» / «Новый чат» —
   обычно слева вверху): старая переписка в том же чате портит ответ.
3. Если в чате есть выбор модели или режима — выбери самый сильный из бесплатных. Режим
   рассуждения («Reasoning», «DeepThink», «Думать дольше») — **необязательно**, включай, если
   доступен.
4. Щёлкни в поле ввода сообщения внизу, вставь (`Ctrl+V`), отправь (`Enter` или стрелка).
   Чат отказался принять длинный текст — прикрепи `prompt-file` файлом (скрепка) и напиши в поле
   «Выполни задание из файла».
5. Дождись конца ответа: пропала кнопка «Stop» / «Остановить». Ответ оборвался на полуслове —
   напиши «продолжай» и дождись снова.
6. Под ответом нажми кнопку «Копировать» (значок двух листов). Её нет — выдели ответ мышью
   целиком и `Ctrl+C`.
7. Создай в `answer-dir` файл с именем из таблицы выше, вставь ответ, сохрани. Ответ шёл
   несколькими сообщениями («продолжай») — вставь их подряд в тот же файл.

Готово, когда в `answer-dir` лежит по файлу на каждую модель и ни один не обрывается
на полуслове. Моделей меньше, чем в `models`, — не страшно: агенту хватает двух-трёх.

Правка ответа руками не нужна: файл сохраняется как есть, со всеми опечатками модели.
