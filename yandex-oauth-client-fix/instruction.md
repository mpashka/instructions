# Инструкция: вход через Яндекс на {{site}} отклонён

Добавить приложению Яндекс ID адрес возврата, на который его посылает сайт. Пока адреса нет в
списке, Яндекс отвечает «Неверный redirect_uri» и до окна согласия дело не доходит. Само приложение
уже заведено; секретов инструкция не касается.

**ИИ-агент** — Claude, Codex или другой ИИ-агент, от которого ты получил эту инструкцию.

Составлена 2026-09-20 без сверки с экраном: если пункт меню называется иначе — ищи по смыслу.

## Шаги

1. Открой <https://oauth.yandex.ru/client/{{yandex_client_id}}> — страница приложения с ClientID
   `{{yandex_client_id}}`. Попросит войти — входи той учётной записью, которой заводил приложение.
   Страница не открылась — открой <https://oauth.yandex.ru/> и найди приложение в списке по
   этому же ClientID.
2. Нажми **Редактировать**.
3. Пролистай до **Платформы приложения**. Отметка **Веб-сервисы** должна стоять; под ней —
   список полей **Redirect URI** с уже заведёнными адресами.
4. Нажми **+ Добавить** под последним адресом и введи в появившееся поле:

   ```text
   {{redirect_uri}}
   ```

   Ровно так, без завершающего `/`. Прежние адреса не трогай и не удаляй: по ним работает вход с
   компьютера разработчика.
5. Пролистай до конца и нажми **Сохранить**.

## Как понять, что удалось

На странице приложения в списке **Redirect URI** виден добавленный адрес, а вход через Яндекс на
{{site}} доходит до окна согласия и возвращает на сайт.

Если Яндекс по-прежнему отвечает ошибкой — перешли ИИ-агенту её текст целиком вместе с адресом из
строки `redirect_uri=` в адресной строке браузера.
