# Инструкция: разрешить установку приложения по USB на Xiaomi (HyperOS, MIUI)

Цель: ИИ-агент (Claude, Codex или другой, от которого ты получил эту инструкцию) ставит приложение
на телефон Xiaomi с компьютера командой `adb install`. Ты — человек с телефоном в руках. Без этого
установка падает с `INSTALL_FAILED_USER_RESTRICTED: Install canceled by user`: телефон либо
запрещает установку по USB вовсе, либо показал окно подтверждения, и его не нажали вовремя.

Составлена 2026-09-16 по памяти о HyperOS 2, без сверки с экраном: если пункт называется иначе —
ищи по смыслу.

## Один раз: включить установку по USB

1. Телефон разблокирован, подключён кабелем, режим разработчика уже включён.
2. «Настройки» → «Дополнительные настройки» → «Для разработчиков».
3. Включи «Установка через USB» (Install via USB). Телефон может попросить войти в аккаунт Xiaomi и
   держать SIM-карту в телефоне — это требование Xiaomi, обойти его нельзя.
4. Там же «Отладка по USB (настройки безопасности)» — **можно пропустить**, для установки не нужна.

Удалось, если переключатель «Установка через USB» остался включённым после выхода из экрана.
Напиши ИИ-агенту:

```text
разрешил установку по USB, повторяй
```

## Каждый раз: подтвердить установку

1. Держи телефон разблокированным перед собой, пока ИИ-агент запускает установку.
2. Появится окно «Установить приложение через USB?» с таймером около 10 секунд — нажми
   «Установить». Не успел — напиши ИИ-агенту `не успел, повтори`.
3. Может появиться второе окно проверки безопасности (сканирование приложения) — нажми
   «Установить» или «Всё равно установить».

## Если окно закрывается само

Бывает (HyperOS 2, 2026-09-16): окно подтверждения мелькает и исчезает. Тогда напиши ИИ-агенту
`окно закрывается само, положи APK в Download` — он скопирует файл на телефон и назовёт его имя.
Дальше:

1. Открой на телефоне «Файлы» (или «Проводник») → «Download».
2. Нажми на файл `.apk` с названным именем.
3. Нажми «Установить». Спросит разрешение ставить приложения из этого источника — разреши и вернись
   назад, если установка не продолжилась сама.
4. Удалось, если появилась кнопка «Открыть».

Окно не появилось вовсе — перешли ИИ-агенту, что было на экране.
