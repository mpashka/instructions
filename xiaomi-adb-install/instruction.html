«{{app_name}}» на Xiaomi: установка по USB

ИИ-агент ставит приложение «{{app_name}}» на твой телефон Xiaomi с компьютера, по кабелю. Телефон требует подтвердить установку нажатием — это и есть твоя часть. Время — 2 минуты.

ИИ-агент — Claude, Codex или другой ИИ-агент, от которого ты получил эту инструкцию.

Составлена 2026-09-16 по HyperOS 2, дополнена 2026-09-17 (POCO F8 Pro, HyperOS 3, Android 16 — проверено, чем открывается экран разработчика). Экраны нарисованы по памяти: если пункт называется иначе — ищи по смыслу. Обведено то, что нажимать.

1Подключить телефон

Разблокируй телефон и подключи его кабелем к компьютеру. Спросит «Разрешить отладку по USB?» — отметь «Всегда разрешать с этого компьютера» и нажми «Разрешить».

Напиши ИИ-агенту:

телефон подключён, проверь

ИИ-агент видит телефон — он сам проверит, включена ли «Установка через USB», и скажет, нужен ли шаг 2. Не видит — значит, на телефоне не включён режим разработчика или отладка по USB: ниже, где они лежат.

ТелефонВключить режим разработчикаГде потом «Для разработчиков»
Xiaomi, Redmi, POCO — HyperOS 1–3«Настройки» → «О телефоне» → 7 раз нажать на «Версия ОС» (или «Версия Xiaomi HyperOS»)«Настройки» → «Расширенные настройки» → «Для разработчиков»
Xiaomi, Redmi, POCO — MIUI 12–14«Настройки» → «О телефоне» → «Все параметры» → 7 раз на «Версия MIUI»«Настройки» → «Расширенные настройки» (или «Дополнительно») → «Для разработчиков»

Спросит PIN-код экрана — введи. Появится «Вы стали разработчиком». В разделе «Для разработчиков» включи «Отладка по USB» и переподключи кабель. Поиск в «Настройках» находит раздел не всегда — пункты из таблицы надёжнее.

2Включить «Установка через USB» один раз, только если ИИ-агент сказал, что выключено

ИИ-агент сам откроет на телефоне экран «Для разработчиков» — телефон должен быть разблокирован. Экран не открылся — путь в таблице шага 1.

‹ Для разработчиков
Отладка по USB
Установка через USB
Отладка по USB (настройки безопасности) не нужна

Пролистай вниз до раздела «Отладка» и включи «Установка через USB». Этот пункт есть только у Xiaomi, Redmi и POCO — на других телефонах шага 2 нет.

Телефон может попросить войти в аккаунт Xiaomi и держать SIM-карту в телефоне — это требование Xiaomi, обойти его нельзя. Удалось, если переключатель остался включённым после выхода из экрана.

3Подтвердить установку

Напиши ИИ-агенту, что телефон готов, и держи его разблокированным перед собой:

телефон подключён, ставь

Через несколько секунд на телефоне появится окно — у тебя около 10 секунд:

Нажми «Установить». Появилось второе окно проверки безопасности — «Всё равно установить». Удалось, если ИИ-агент сообщил, что установка прошла.
