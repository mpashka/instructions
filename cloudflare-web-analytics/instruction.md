# Инструкция: сайт {{hostname}} в Cloudflare Web Analytics — токен счётчика

Получить токен счётчика Cloudflare Web Analytics для сайта {{hostname}}. Токен — 32 символа, он
вставляется в HTML страницы и **секретом не является**: его видит любой, кто откроет исходный код
страницы.

**ИИ-агент** — Claude, Codex или другой ИИ-агент, от которого ты получил эту инструкцию.

Составлена 2026-09-14 без сверки с экраном: если пункт меню называется иначе — ищи по смыслу
(«Web Analytics», «Add a site»).

## Шаги

1. Открой https://dash.cloudflare.com и войди в аккаунт. Аккаунта нет — «Sign up», бесплатного
   плана достаточно; домен в Cloudflare переносить **не нужно**.
2. В левом меню открой **Analytics & Logs → Web Analytics**. Такого пункта нет — в строке поиска
   дашборда набери «Web Analytics».
3. Нажми **Add a site**.
4. В поле **Hostname** введи `{{hostname}}`.
5. Если спросят способ установки — выбери вставку JavaScript-фрагмента (**Manual / JS Snippet**),
   а не автоматическую установку: автоматическая работает только для доменов, чей DNS в
   Cloudflare.
6. Нажми **Done** / **Add**. Откроется страница с фрагментом кода вида:

   ```html
   <script defer src="https://static.cloudflareinsights.com/beacon.min.js"
     data-cf-beacon='{"token": "0123456789abcdef0123456789abcdef"}'></script>
   ```

   Сайт уже был добавлен раньше — в списке Web Analytics нажми **Manage site** у {{hostname}},
   фрагмент там же.
7. Скопируй из фрагмента **только значение `token`** — 32 символа между кавычками.
8. Напиши ИИ-агенту одну строку, подставив токен:

   ```text
   токен Web Analytics: <32 символа из шага 7>
   ```

Готово, когда строка отправлена. Счётчик считает всё, что открыто на {{hostname}}, — отдельные
страницы потом различаются фильтром по пути (**Path**) в отчёте Web Analytics.

Необязательно: в настройках сайта в Web Analytics можно включить уведомления и выключить сбор
**Core Web Vitals** — на подсчёт визитов это не влияет.
