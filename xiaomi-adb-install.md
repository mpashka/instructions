# Инструкция: разрешить установку приложения по USB на Xiaomi (HyperOS, MIUI)

Цель: `adb install` с компьютера ставит приложение на телефон Xiaomi. Без этого установка падает с
`INSTALL_FAILED_USER_RESTRICTED: Install canceled by user` — телефон либо запрещает установку по USB
вовсе, либо показал диалог подтверждения, и его не нажали вовремя.

Составлена 2026-09-16 по памяти о HyperOS 2, без сверки с экраном: если пункт называется иначе —
ищи по смыслу и поправь инструкцию.

## Один раз: включить установку по USB

1. Телефон разблокирован, подключён кабелем, режим разработчика уже включён (иначе `adb devices` его
   бы не видел).
2. «Настройки» → «Дополнительные настройки» → «Для разработчиков».
3. Включи «Установка через USB» (Install via USB). Телефон может попросить войти в аккаунт Xiaomi и
   держать SIM-карту в телефоне — это требование Xiaomi, обойти его нельзя.
4. Там же включи «Отладка по USB (настройки безопасности)» — **можно пропустить**, для установки не
   нужна, нужна только для управления телефоном с компьютера.

Удалось, если переключатель «Установка через USB» остался включённым после выхода из экрана.

## Каждый раз: подтвердить установку

1. Держи телефон разблокированным перед собой, пока агент запускает установку.
2. Появится окно «Установить приложение через USB?» с таймером около 10 секунд — нажми
   «Установить». Не успел — установка отменится, скажи агенту повторить.
3. Может появиться второе окно проверки безопасности (сканирование приложения) — нажми
   «Установить» или «Всё равно установить».

## Если окно закрывается само

Бывает (HyperOS 2, 2026-09-16): окно подтверждения мелькает и исчезает, а агент получает всё тот же
`Install canceled by user`. Тогда агент кладёт APK в папку `Download` телефона (`adb push`), а ставишь
ты:

1. Открой на телефоне «Файлы» (или «Проводник») → «Download».
2. Нажми на файл `.apk`, который назвал агент.
3. Нажми «Установить». Спросит разрешение ставить приложения из этого источника — разреши и вернись
   назад, если установка не продолжилась сама.
4. Удалось, если появилась кнопка «Открыть».

## Что вернуть агенту

Напиши «разрешил, повторяй» — агент запустит установку ещё раз, и ты нажмёшь «Установить» на
телефоне. Если окно не появилось вовсе — напиши, что было на экране.
